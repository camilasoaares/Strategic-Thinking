# Dublin Housing Affordability for First-Time-buyers
## Project Overview
This project aims to assess estimated housing affordability for First-Time-Buyers in Dublin.
## Data Sources
- Project Price Register (PPR)
  The PPR dataset contains rediential property transaction information for Dublin, including sale prices, transaction dates, property types and market-price status.
- Central Bank of Ireland - New Mortgage Lending Data
  This dataset provides aggregate mortgage lending indicators for Frs-Time-Buyers, including average loan sizes and property values for 2024 and 2025.
